# СпортАкадемКлуб

Адаптивный сайт детского футбольного клуба на React, TypeScript и Vite. Без эмодзи, внешних шрифтовых сервисов и сторонних счётчиков. Фотографии школы и шрифт Montserrat хранятся локально.

## Запуск

Требуются Node.js 22+ и npm. В облачной среде проверены Node.js 24.19.0 и npm 11.9.0.

```bash
cd /workspace/football
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run dev -- --port 5173
```

Производственная сборка: `npm run build`. Результат — каталог `dist`, который можно разместить на статическом хостинге. Проверка сборки: `npm run preview -- --port 4173`.

## Данные и дизайн

Информация и фотографии перенесены с https://dfc-sportacadem.tb.ru/ 2 октября 2026 года. https://nrdn-junior.ru/ использован как ориентир по современному оформлению; данные другой школы не переносились.

Сохранены разделы «О клубе», «Тренер», «Программа», «Залы», «Расписание», «Стоимость» и «Контакты», а также запись на бесплатную пробную тренировку. Дополнительно добавлены ответы на вопросы родителей.

Фирменные цвета из исходного сайта: зелёный `#11651a`, жёлтый `#ffdd2d`, красный `#db320b`. Цветовые переменные находятся в `src/styles.css`. Контакты, расписание, абонементы и программы — в `src/content.ts`.

Цены акции на пробный абонемент относятся к октябрю. Перед публикацией следует подтвердить срок акции, наличие мест и актуальность условий с клубом. Год рождения и возрастные группы сохранены из источника.

## Запись

Окно записи готовит персональное сообщение для администратора и открывает Telegram школы с текстом. Посетитель самостоятельно отправляет его. Для Max можно скопировать текст и открыть официальный контакт. Также работают звонок по телефону и переход к адресу в Яндекс Картах.

Сайт не сохраняет персональные данные и не имитирует отправку заявки. Для получения заявок непосредственно с сайта потребуется отдельно подключить сервис обработки форм и необходимые документы по обработке персональных данных.

## Проверки

`npm run build` выполняет проверку TypeScript и производственную сборку.

В облачной среде доступны Python Playwright и `/usr/bin/chromium`. При работающем Vite:

```bash
python3 scripts/smoke.py
```

Проверяются все разделы, точная палитра, загрузка изображений, персонализация и копирование сообщения, восстановление фокуса после закрытия окна, FAQ, расписание с управлением клавиатурой, галерея, выбор абонемента, мобильное меню, ссылки и отсутствие горизонтальной прокрутки при ширинах от 320 до 1440 px. Снимки экрана сохраняются в `/tmp/football-smoke`.

Проект уже находится в изолированной облачной среде; используйте существующий checkout, отдельный Git worktree не нужен.

## GitHub Pages

Публикация подготовлена для https://egkodin.github.io/football/ . Относительные пути позволяют размещать сайт в подпапке без потери фотографий и шрифтов.

В репозитории GitHub откройте **Settings → Pages → Build and deployment** и выберите **Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает сайт и публикует `dist` при каждом push в `main`. Если первоначальный запуск произошёл до включения Pages, повторно запустите workflow **Deploy website to GitHub Pages** на вкладке **Actions**.
