# СпортАкадемКлуб

Адаптивный сайт футбольной школы на React, TypeScript и Vite. Сохранены семь разделов, зелёно-жёлтая палитра, расписание, цены и контакты [исходного сайта](https://dfc-sportacadem.tb.ru/). [Народная Джуниор](https://nrdn-junior.ru/) — ориентир по оформлению. Данные сверены 2 октября 2026 года. Присланная эмблема находится в `public/images/club-logo.jpg`.

## Запуск

Node.js 22+:

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

Откройте http://127.0.0.1:5173/.

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

Сборка выполняет проверку TypeScript. Готовые файлы находятся в `dist/`; относительные пути поддерживают размещение в подпапке.

## Редактирование

Контакты, группы, абонементы и фотографии — `src/content.ts`. Разметка — `src/App.tsx`, оформление — `src/styles.css`, правила дизайна — `DESIGN.md`. Шрифт и изображения хранятся локально. Иллюстрация первого экрана взята из исходного сайта; это не документальная фотография учеников. Фото тренера и залов также из исходного сайта.

Октябрьские скидки сохранены из источника. Перед публичным запуском клубу нужно подтвердить сроки акции и актуальность расписания и цен.

## Запись на тренировку

Диалог готовит сообщение администратору и открывает Telegram клуба с текстом. Посетитель отправляет сообщение самостоятельно. Для Max есть копирование текста и ссылка на контакт. Если браузер запрещает копирование, текст остаётся доступным для ручного копирования. Работают звонок и ссылка на Яндекс Карты.

Сайт не хранит введённые данные и не имитирует отправку заявки. Отправка непосредственно с сайта потребует отдельного подключения приёмника заявок.

В контактах встроены Яндекс Карты: координаты отметки взяты из `data-map` исходного сайта (55.801081, 37.760081). Используется публичный iframe-виджет, без ключа API конструктора Т-Банка. Виджет загружается с серверов Яндекса; адрес для отдельного открытия карты остаётся доступен под ним.

## Проверки в браузере

При запущенном сервере тест проверяет разделы, палитру и эмблему, загрузку изображений, запись и отказ буфера обмена, возврат фокуса, FAQ, клавиатурное управление расписанием, галерею, абонементы и мобильное меню. Проверяются девять размеров от 320 до 1440 px. Снимки экрана сохраняются в `/tmp/football-smoke`.

Галерея дополнительно проверяется при медленной загрузке следующего снимка и по промежуточным кадрам переходов вперёд/назад: предыдущий кадр остаётся непрозрачным, масштаб и высота не меняются, изображения не пересоздаются. В smoke содержимое внешнего iframe карты подменяется тестовой страницей; проверяются реальный URL, исходные координаты, доступный заголовок и lazy loading. Отрисовку и управление самой картой нужно проверять отдельно с доступом к серверам Яндекса.

Проверено 3 октября 2026 года: production-сборка и расширенный smoke прошли, включая пять переходов галереи в обе стороны, медленную загрузку, ошибку/повторную попытку, быстрый ввод и reduced motion. Реальный виджет карты отрисовался на 1440 и 390 px; кнопка приближения изменила масштаб со 100 на 50 м. В проверочном Chrome прямые запросы к ресурсам Яндекса давали `ERR_SOCKET_NOT_CONNECTED`, поэтому для этого отдельного live-теста реальные ответы доставлялись через `route.fetch()` сетевого клиента Playwright. Эта маршрутизация использовалась только в тесте; сайт напрямую встраивает публичный iframe. Прямое соединение проверочного Chrome с Яндексом остаётся неподтверждённым.

Если Playwright ещё не установлен:

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/smoke.mjs
```

Проверка производственной сборки при запущенном `npm run preview`:

```bash
FOOTBALL_BASE_URL=http://127.0.0.1:4173/ node scripts/smoke.mjs
```

Можно задать `FOOTBALL_BROWSER` — путь к уже установленному Chrome, `PLAYWRIGHT_PATH` — путь к установленному пакету Playwright, `FOOTBALL_SCREENSHOTS` — каталог снимков.

В `.github/workflows/pages.yml` сохранён workflow GitHub Pages. Публикация из этой рабочей сессии не выполнялась.

Иконки: Icons8 Material Outlined (`m_outlined`), локальные PNG 96 × 96 px. Бесплатное использование PNG до 100 px требует ссылки на Icons8; ссылка находится в подвале. Условия: https://icons8.com/license. Идентификаторы, названия и превью всех иконок сохранены в `icons8.json`. SVG недоступны в текущем подключении Icons8.

Главный кадр `public/images/hero-training.jpg` создан встроенным imagegen 2 октября 2026 года: естественная спортивная фотография детской тренировки, зелёно-жёлтая форма, мальчик ведёт мяч, два ребёнка на фоне; без текста, гигантской эмблемы и графических мазков. Кадр квадратный, основной игрок и мяч находятся в центре для адаптивного кадрирования. Это рекламное сгенерированное изображение.

Портрет тренера и пять фотографий залов заменены на нейросетевые версии `*-upscaled.jpg`. Исходные фотографии сохранены рядом. Фактические размеры и запросы встроенного imagegen записаны в [IMAGEGEN.md](IMAGEGEN.md). Первый кадр не менялся при этой обработке.
