# SEO СпортАкадемКлуба

Основной адрес: **https://cfc-sportacadem.ru/**. Проверка: 6 октября 2026 года.

## Что исправлено

- При каждой сборке React формирует полный HTML страницы. Тексты, тренеры, абонементы и расписание всех возрастных групп доступны до запуска JavaScript.
- H1, title, description и вводный текст описывают футбол для детей в Москве, метро Черкизовская и Локомотив. Структура разделов и цвета сохранены.
- Добавлены canonical на основной HTTPS-адрес, Open Graph, Twitter Card и разрешение больших изображений в поиске.
- JSON-LD описывает клуб, адрес, телефон, часы работы, официальные соцсети и цены существующих абонементов. Цены берутся из `src/content.ts`. Октябрьские предложения имеют срок действия до 31 октября 2026 года.
- При сборке создаются `dist/robots.txt` и `dist/sitemap.xml`. В sitemap только реальная главная страница: якоря разделов не являются отдельными страницами.
- Для первого экрана добавлены WebP 768 и 1254 px с JPEG как запасным форматом. Размеры: 75 068 и 147 318 байт вместо 398 597 байт; уменьшение на 81% и 63%. Оригинал сохранён.
- Кириллический и латинский шрифты загружаются заранее. Фотографии ниже первого экрана и карта сохраняют ленивую загрузку.
- Без JavaScript доступны расписание всех групп, ответы на вопросы, биографии и ссылки для записи. После гидратации работают существующие интерактивные элементы.
- Добавлена проверка SEO в GitHub Actions перед публикацией.

Основа: [Google о JavaScript и предварительном рендеринге](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [LocalBusiness](https://developers.google.com/search/docs/appearance/structured-data/local-business), [правила структурированных данных](https://developers.google.com/search/docs/appearance/structured-data/sd-policies), [Sitemap в Яндексе](https://yandex.ru/support/webmaster/ru/controlling-robot/sitemap).

## Проверка и запуск

```bash
npm ci --no-audit --no-fund
npm run build
npm run test:seo
npm run preview -- --host 127.0.0.1 --port 4173
```

`build` включает TypeScript, Vite и предварительный рендеринг. Сервер для сборки не требуется. Временные серверные модули удаляются; дополнительных зависимостей нет. `test:seo` проверяет итоговый HTML, метаданные, цены в разметке, ссылки на ресурсы и файлы индексации.

Браузерная проверка использует имеющийся Playwright; при необходимости задайте `PLAYWRIGHT_PATH` и `FOOTBALL_BROWSER`:

```bash
FOOTBALL_BASE_URL=http://127.0.0.1:4173/ node scripts/smoke.mjs
```

Она проверяет девять ширин 320–1440 px, клавиатуру, меню, запись, галерею и восстановление после ошибки изображения; отдельно — готовый HTML, страницу без JavaScript и загрузку галереи до гидратации. Карта и пиксель в этом тесте подменены ответами: это проверка интеграционного кода, а не доступности внешних сервисов.

## Что нужно после публикации

1. Дождаться успешного GitHub Actions и проверить главную, `/robots.txt`, `/sitemap.xml` на основном домене: все должны отвечать 200. В HTML ответа уже должны присутствовать тексты клуба и JSON-LD.
2. В Яндекс Вебмастере выбрать HTTPS-версию сайта, добавить `https://cfc-sportacadem.ru/sitemap.xml`, запросить переобход главной, проверить регион и диагностику. Существующий тег подтверждения Яндекса сохранён.
3. В Google Search Console подтвердить домен через DNS или выданный сервисом тег, отправить sitemap, проверить URL и запросить индексацию. Токен Google не предоставлен, подтверждение не выполнено.
4. Проверить опубликованный адрес в [Rich Results Test](https://search.google.com/test/rich-results) и [PageSpeed Insights](https://pagespeed.web.dev/). Оценивать полевые Core Web Vitals отдельно от лабораторных замеров.
5. Заполнить или обновить карточки Яндекс Бизнеса и Google Business Profile: название, телефон, адрес и ссылка должны совпадать с сайтом. Добавлять реальные фотографии и отзывы родителей.
6. Проверить старый сайт `dfc-sportacadem.tb.ru`: если он дублирует этот сайт и вы управляете им, настроить перенаправление или canonical на основной домен.
7. Перед ноябрём обновить видимые условия акции и цены. При изменении адреса, телефона или часов работы синхронизировать видимый текст и JSON-LD в `scripts/prerender.mjs`.

## Приоритет продвижения

Начальные запросы для проверки в Wordstat и отчётах поисковых систем: «футбол для детей Черкизовская», «детская футбольная секция Локомотив», «футбол для детей Сиреневый бульвар», «СпортАкадемКлуб», «футбол для детей 3–5 лет Москва». Частотность и позиции не измерены: это варианты запросов, а не подтверждённое семантическое ядро.

Далее развивать контент на основании вопросов родителей и данных поиска: реальные тренировки, достижения, объяснение программы и полезные материалы. Отдельные страницы нужны для самостоятельных тем с полезным содержанием; копии лендинга под похожие ключи не добавлены.

## Границы проверки

Локально прошли `npm run build`, `npm run test:seo` и production smoke-тест в Chrome, включая все девять ширин экрана, страницу без JavaScript и отложенную гидратацию. Скриншоты первого экрана на телефоне и компьютере просмотрены.

На опубликованном сайте подтверждены HTTPS 200, HTTP → HTTPS 301 и www → основной домен 301. Сертификат GitHub Pages одобрен, HTTPS включён. До этой работы `robots.txt` и `sitemap.xml` отсутствовали.

Публикация запускается существующим workflow при пуше в `main`; её результат проверяется в GitHub Actions. Отправка sitemap, доступ в кабинеты, подтверждение Google, внешняя проверка новой разметки и измерение позиций не выполнены. Гарантировать топ или сроки роста нельзя; технические правки подготавливают сайт к продвижению.
